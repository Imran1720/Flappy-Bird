# 🐦 Flappy Bird Clone
A simple yet addictive Flappy Bird clone built with Unity — tap, flap, and dodge obstacles to beat your high score!

### Features
<ul>
<li> 🐦 Simple "tap to flap" physics-based control.</li>
<li> 🛑 Obstacles (pipes) spawn with random heights.</li>
<li> 🎯 Infinite gameplay loop.</li>
<li> 🧮 Score tracking system — try to beat your best run!</li>
<li> 🎵 Sound effects for flaps and collisions.</li>
<li> 🖥️ UI for Start, Game Over, and Restart.</li>
<li> 🚀 Build available for WebGL.</li>
</ul>

### Game Loop:
<ol>
  <li><b>Main Menu –</b> Start the game.</li>
  <li><b>In-Game – </b> Flap to avoid pipes and gain points.</li>
  <li><b>Collision –</b> Hitting a pipe or ground ends the game.</li>
  <li><b>Game Over –</b> Display score and option to restart.</li>
</ol>

### UI:
<ol>
<li><b>Start Screen: </b>Play button to begin.</li>
<li><b>In-Game UI: </b>Displays current score.</li>
<li><b>Game Over Screen: </b>Shows final score and allows restart.</li>
</ol>

## How to Play:
<ol>
    <ul>
      <li><b>Mouse click</b> to make the bird flap.</li>
         <li><b>Stay in the air </b>and navigate between pipes.</li>
         <li><b>Avoid collisions </b>with pipes and the ground.</li>
      <li><b>Try to beat your high score </b>with each attempt!</li>
    </ul>
</ol>
